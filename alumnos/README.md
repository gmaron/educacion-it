# Alumnos

Cada uno trabaja en su carpeta: `alumnos/<tu-usuario-de-github>/`. Adentro va tu especificación (`especificacion.md`) y, desde el sábado 2, el código de tu app.

## La lista de la cursada

Este archivo es el único que tocamos todos. Agregá tu línea al final de la tabla en el mismo PR de tu especificación.

Si dos personas lo editan al mismo tiempo, GitHub va a avisar que hay un **conflicto**. Es a propósito: resolverlo es parte del juego. Quedate con las dos líneas, la tuya y la del otro.

| Usuario de GitHub | Una cosa que quiero aprender |
| --- | --- |
| *@tu-usuario (ejemplo)* | *Resolver un conflicto de merge* |
